# Awesome App Template

Добро пожаловать в ваш новый проект, сгенерированный с помощью `create-awesome-app`! Этот шаблон предоставляет надежную основу для создания современных, реактивных веб-приложений на чистом JavaScript с использованием архитектуры Feature-Sliced Design (FSD).

## 🚀 Быстрый старт

1.  **Установите зависимости:**
    Откройте терминал в корневой папке проекта и выполните команду:

    ```bash
    npm install
    ```

2.  **Запустите сервер для разработки:**
    Эта команда запустит локальный сервер с горячей перезагрузкой (Hot Module Replacement).
    ```bash
    npm run dev
    ```
    После запуска ваш проект будет доступен по адресу, указанному в терминале (обычно `http://localhost:5173`).

## 📜 Доступные скрипты

- `npm run dev`: Запустить сервер для разработки.
- `npm run build`: Собрать оптимизированную версию проекта для продакшена.
- `npm run preview`: Запустить локальный сервер для предпросмотра продакшн-сборки.
- `npm run create:component`: Интерактивный CLI для создания нового FSD-компонента по шаблону.
- `npm run cleanup`: **(Внимание!)** Удаляет все демо-компоненты, виджеты, страницы и документацию, оставляя чистый шаблон для вашего проекта.

## 🏛️ Архитектура: Feature-Sliced Design (FSD)

Проект строго следует принципам FSD для обеспечения масштабируемости и простоты поддержки.

- **`src/0-shared`**: Переиспользуемый код, не имеющий отношения к бизнес-логике (UI-кит, хелперы, API-клиенты).
- **`src/1-entities`**: Бизнес-сущности и их компоненты (например, `UserCard`, `ProductInfo`).
- **`src/2-features`**: Действия пользователя, бизнес-сценарии (например, `ReloadUserButton`, `AddToCart`).
- **`src/3-widgets`**: Композиционные блоки, объединяющие `entities` и `features` в независимые секции для страниц (например, `UserProfileWidget`).
- **`src/4-pages`**: Страницы приложения, которые собираются из виджетов.
- **`src/5-app`**: Инициализация приложения, глобальные стили, роутер и стор.

**Основное правило FSD:** Слои могут импортировать только из слоев, расположенных ниже (например, `widgets` могут импортировать из `features`, `entities` и `shared`, но не из `pages`).

## 💡 Реактивность

Проект использует легковесную систему реактивности на основе ES6 Proxy, что позволяет писать декларативный код без необходимости подключения тяжелых фреймворков.

- **`ReactiveComponent`**: Базовый класс для всех компонентов. Когда его `.state` изменяется, компонент автоматически перерисовывается.
- **`createStore`**: Фабрика для создания глобальных или локальных хранилищ (сторов). Компоненты могут подписываться на изменения в сторе и обновляться.
